## 1. Детальний опис задачі

### 1.1 Продуктова лінійка
Підприємство виробляє три види продукції:
1. **Сумка-шопер (x₁)**
   - Матеріал: щільна бавовна
   - Витрати тканини: 1.2 м²/од
   - Трудомісткість: 0.5 год/од
   - Прибуток: 45 грн/од

2. **Фрутівка (x₂)**
   - Матеріал: екологічна сітка
   - Витрати тканини: 0.8 м²/од
   - Трудомісткість: 0.3 год/од
   - Прибуток: 30 грн/од

3. **Ланч-мешок (x₃)**
   - Матеріал: органічний лляний полотен
   - Витрати тканини: 0.5 м²/од
   - Трудомісткість: 0.2 год/од
   - Прибуток: 25 грн/од

### 1.2 Ресурсні обмеження
| Ресурс               | Доступний обсяг | Одиниця виміру |
|----------------------|-----------------|----------------|
| Тканина              | 1,200           | м²/міс         |
| Робочий час          | 800             | год/міс        |
| Потужність фарбування| 2,000           | од/міс         |

### 1.3 Контрактні зобов'язання
- Мінімальний випуск шоперів: 200 од/міс
- Мінімальний випуск фруктівок: 300 од/міс
- Мінімальний випуск ланч-мешків: 150 од/міс

## 2. Математична модель

### 2.1 Формалізація задачі
**Цільова функція:**
```math
\max Z = 45x₁ + 30x₂ + 25x₃
```

**Система обмежень:**
```
1.2x₁ + 0.8x₂ + 0.5x₃ ≤ 1200 (тканина)
0.5x₁ + 0.3x₂ + 0.2x₃ ≤ 800 (робочий час)
x₁ + x₂ + x₃ ≤ 2000 (фарбування)
x₁ ≥ 200
x₂ ≥ 300
x₃ ≥ 150
```

### 2.2 Особливості моделі
- Задача містить 3 змінні рішення
- Всі обмеження лінійні
- Всі параметри детерміновані
- Вимоги до цілочисельності рішень

## 3. Реалізація розв'язку

### 3.1 Використані інструменти
- Бібліотека `PuLP` для Python
- Симплекс-метод
- Аналіз чутливості

### 3.2 Код реалізації
```python
from pulp import *
import matplotlib.pyplot as plt
import numpy as np

# Ініціалізація моделі
model = LpProblem("EcoBags_Production", LpMaximize)

# Визначення змінних
products = {
    'Shoper': {'var': LpVariable("Shoper", 200, None, LpInteger), 'profit': 45},
    'FruitBag': {'var': LpVariable("FruitBag", 300, None, LpInteger), 'profit': 30},
    'LunchBag': {'var': LpVariable("LunchBag", 150, None, LpInteger), 'profit': 25}
}

# Цільова функція
model += lpSum([products[p]['profit'] * products[p]['var'] for p in products])

# Обмеження
model += 1.2*products['Shoper']['var'] + 0.8*products['FruitBag']['var'] + 0.5*products['LunchBag']['var'] <= 1200, "Fabric"
model += 0.5*products['Shoper']['var'] + 0.3*products['FruitBag']['var'] + 0.2*products['LunchBag']['var'] <= 800, "Labor"
model += products['Shoper']['var'] + products['FruitBag']['var'] + products['LunchBag']['var'] <= 2000, "Dyeing"

# Розв'язання
model.solve()
```
